      How to use
      

        
    
          
  1. Paste the original log into the left panel.
    2. 
          
  2. Select Sanitize text. Clearly sensitive values are hidden automatically.
    3. 
          
  3. To hide any additional word or phrase, highlight it in the left panel and select Mask selected text.
    4. 
          
  4. Review any uncertain public IPs, domains, hostnames or usernames and mask only the ones you choose. Your choices are remembered in this tab until you clear everything or close it.
    5. 
          
  5. Review the masked values. Select Unmask beside any one value you want restored everywhere without changing the other masks.
    6. 
          
  6. Copy the sanitized result when it is ready.
